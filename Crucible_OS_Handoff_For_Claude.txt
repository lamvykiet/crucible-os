## PHẦN 2: CHI TIẾT CẤU TRÚC HỆ THỐNG VÀ TRÁCH NHIỆM TỪNG FUNCTION

Dự án dùng **Next.js App Router, Tailwind CSS, Prisma, PostgreSQL**.

### 2.1 Cây thư mục (Directory Tree)
```text
SRC
├── middleware.ts
├── app
│   ├── api
│   │   ├── ai/chat/route.ts (Xử lý gọi Gemini API)
│   │   ├── drive/download/route.ts (Tải/Stream PDF từ Google Drive)
│   │   ├── finance/dashboard/route.ts (Query DB Prisma tính tổng thu chi theo tháng)
│   │   ├── ocr/route.ts (Đọc hóa đơn)
│   │   └── video/download/route.ts (Tính năng Tải Video - CẦN LÀM)
│   ├── finance/page.tsx (Trang chủ Finance, quản lý state selectedMonth)
│   ├── knowledge/[id]/page.tsx (Trang đọc tài liệu 3-Panel)
│   ├── learning/subject/[id]/page.tsx (Trang học tập 3-Panel)
├── components
│   ├── finance
│   │   ├── DashboardTab.tsx (Hiển thị biểu đồ và Card số liệu thật từ API)
│   │   ├── FinanceHeader.tsx (Chứa Date Picker cần làm đẹp giống GCal)
│   ├── knowledge
│   │   ├── IdeaTrackerTab.tsx (CẦN LÀM: Logic lưu ý tưởng)
│   │   ├── VideoDownloaderTab.tsx (CẦN LÀM: Giao diện tải video)
├── lib
│   └── LanguageContext.tsx (Quản lý đa ngôn ngữ)
```

### 2.2 Trách nhiệm chi tiết của các Modules chính

#### **MODULE FINANCE**
- **File:** `src/app/api/finance/dashboard/route.ts`
  - **Trách nhiệm:** Nhận param `?month=YYYY-MM`. Truy vấn bảng `Transaction` trong Prisma lọc từ ngày đầu tháng đến cuối tháng. Phân loại `type.toLowerCase() === 'income'` và `'expense'`. Trả về JSON tổng hợp.
  - **Việc Claude cần làm:** Audit lại code tính toán, kiểm tra xem timezone có làm sai ngày tháng không, thêm API tính ngân sách (Budget).
- **File:** `src/components/finance/DashboardTab.tsx`
  - **Trách nhiệm:** Dùng `useEffect` gọi API dashboard khi `selectedMonth` thay đổi. Render UI hiển thị số tiền.

#### **MODULE KNOWLEDGE / LEARNING (3-PANEL UI)**
- **File:** `src/app/learning/subject/[id]/page.tsx` & `knowledge/[id]/page.tsx`
  - **Trách nhiệm:** Duy trì State Machine gồm `activeDocument` (string | null), `messages` (mảng chat), `input`. 
  - **Logic:** 
    1. Click File ở Panel 1 -> `setActiveDocument(filename)`.
    2. Panel 2 re-render: Kích hoạt Document Reader View (thẻ `<iframe src="/api/drive/download">`).
    3. Click "Đóng tài liệu" -> `setActiveDocument(null)` -> Panel 2 hiện lại Chat View.
    4. Chat View: Nhập text -> Submit hàm `handleSend` -> Fetch `/api/ai/chat`.
  - **Việc Claude cần làm:** Đảm bảo UI 3 cột này hoạt động không có bug, iframe PDF render mượt mà, chiều cao 100vh được tính toán đúng (không tràn viền).

#### **MODULE AI API**
- **File:** `src/app/api/ai/chat/route.ts`
  - **Trách nhiệm:** Khởi tạo `genAI.getGenerativeModel`. Format lại biến `history` truyền từ client sao cho element đầu tiên luôn có `role: 'user'`.
  - **Việc Claude cần làm:** Đảm bảo hàm `history.shift()` không bẻ gãy luồng xử lý nếu người dùng chưa chat gì. Cần test kỹ logic session của Gemini.

## PHẦN 3: CƠ SỞ DỮ LIỆU (PRISMA SCHEMA)

Hệ thống xoay quanh các bảng (Table) cốt lõi sau:

1. **Transaction & TransactionLine**
   - Lưu trữ giao dịch tài chính.
   - Cột quan trọng: `date` (ngày), `type` (Income/Expense/Transfer), `totalAmount` (số tiền), `categoryGroup`.
   - Lưu ý: Dữ liệu import vào đây bằng script tự động, do đó code Dashboard không được dùng dữ liệu giả mà phải `db.transaction.findMany(...)`.

2. **Budget**
   - Ngân sách người dùng đặt ra theo tháng (`period = 'YYYY-MM'`).
   - Cần kết hợp Budget amount và Transaction totalAmount để tính Budget vs Actual trong Dashboard.

3. **Material & DocumentAnnotation**
   - `Material` chứa `driveFileId` (ID file trên Google Drive). Trang đọc PDF sử dụng ID này ghép vào `/api/drive/download?id=...` để hiển thị.

4. **Flashcard & DictionaryItem**
   - Hệ thống thẻ nhớ theo thuật toán FSRS. Sẽ hiển thị ở Panel 3 (Studio) của giao diện học tập.
